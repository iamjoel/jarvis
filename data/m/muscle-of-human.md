# 人体肌肉

## 高密度摘要

**一句话结论**：人体肌肉不是孤立零件，而是按关节动作、姿势稳定和力传导协同工作的收缩系统；居家训练用蹲、髋铰链、推、拉和核心稳定等复合动作，就能覆盖腿、髋、背、腹、胸、肩、臂七类主要肌群。**核心机制**：骨骼肌收缩产生张力，经肌腱牵拉骨骼绕关节运动；同一动作通常由主动肌、协同肌、拮抗肌和稳定肌共同完成。**判断入口**：想在家练全身看“七大肌群与居家训练”；查外观线条看“训练常用肌群地图”；排训练计划先区分大肌群和小肌群；查动作问题看肩胛、核心、髋、膝、踝这些稳定链。**常见误区**：“七大肌群”是健康指南的实用分区，不是精确解剖分类；不存在权威统一的“25 大肌群”标准；“练哪瘦哪”不成立；居家只做俯卧撑和卷腹会漏掉背部拉力与髋铰链。**相关文档**：[运动系统](./musculoskeletal-system.md)、[核心收缩动作指南](../c/core-bracing-guide.md)、[沉肩动作指南](../s/shoulder-depression-guide.md)、[流动式活动度训练](./mobility-flow.md)、[最大摄氧量（VO₂ max）](../v/vo2max.md)。

## 七大肌群与居家训练

“七大肌群”不是一套唯一的解剖学分类。CDC 在成人活动指南中把需要覆盖的主要肌群列为 **腿、髋、背、腹、胸、肩、臂**，因此日常所说的“七大肌群”通常可以这样理解。它们彼此重叠：俯卧撑同时练胸、肩和肱三头肌，划船同时练背和肱二头肌，没必要给每一类都安排孤立动作。

### 七大肌群的常见肌肉名称

#### 1. 腿部肌群

腿部负责支撑体重、伸屈膝关节、控制脚踝以及走跑跳。

| 肌群 | 常见肌肉 | 主要功能 |
|---|---|---|
| 股四头肌 | 股直肌、股外侧肌、股内侧肌、股中间肌 | 伸膝；股直肌还参与屈髋 |
| 腘绳肌 | 股二头肌、半腱肌、半膜肌 | 屈膝、伸髋 |
| 小腿后侧 | 腓肠肌、比目鱼肌 | 脚踝跖屈、提踵、走跑推进 |
| 小腿前外侧 | 胫骨前肌、腓骨长肌、腓骨短肌 | 脚背屈、足部外翻和踝关节稳定 |

训练动作：深蹲、弓步蹲、分腿蹲、罗马尼亚硬拉、提踵、靠墙抬脚尖。

#### 2. 髋部肌群

髋部肌肉连接骨盆和大腿，负责伸髋、屈髋、外展、内收、旋转以及单腿站立时稳定骨盆。

| 肌群 | 常见肌肉 | 主要功能 |
|---|---|---|
| 臀肌 | 臀大肌、臀中肌、臀小肌 | 伸髋、髋外展、旋转和骨盆稳定 |
| 髋屈肌 | 髂肌、腰大肌，合称髂腰肌 | 屈髋、抬腿 |
| 大腿内收肌 | 内收大肌、内收长肌、内收短肌、耻骨肌、股薄肌 | 髋内收，辅助伸髋或屈髋 |
| 髋外侧 | 阔筋膜张肌 | 髋屈曲、外展和膝外侧稳定 |
| 深层外旋肌 | 梨状肌、闭孔内外肌、上下孖肌、股方肌 | 髋外旋和股骨头稳定 |

训练动作：臀桥、髋铰链、单腿硬拉、侧卧抬腿、侧向弹力带走、哥萨克蹲。

#### 3. 背部肌群

背部肌肉负责拉动手臂、控制肩胛骨、维持脊柱姿势和传递上下肢力量。

| 肌群 | 常见肌肉 | 主要功能 |
|---|---|---|
| 背阔肌 | 背阔肌 | 肩关节后伸、内收和内旋 |
| 斜方肌 | 上束、中束、下束 | 肩胛上提、后缩、下压和上回旋 |
| 菱形肌 | 大菱形肌、小菱形肌 | 肩胛后缩和稳定 |
| 脊柱伸肌 | 髂肋肌、最长肌、棘肌，合称竖脊肌 | 脊柱伸展、侧屈和抗屈曲 |
| 深层稳定肌 | 多裂肌、回旋肌等 | 节段性稳定和精细控制脊柱 |
| 肩胛与上臂连接 | 大圆肌 | 肩后伸、内收和内旋 |

训练动作：划船、引体向上、弹力带下拉、俯卧 Y-T-W、鸟狗、髋铰链。

#### 4. 腹部肌群

腹部肌肉不仅负责“卷腹”，更重要的是稳定躯干、建立腹压，并抵抗腰椎过度伸展、侧屈和旋转。

| 肌群 | 常见肌肉 | 主要功能 |
|---|---|---|
| 腹部前侧 | 腹直肌 | 躯干屈曲、抗伸展 |
| 腹部侧面 | 腹外斜肌、腹内斜肌 | 旋转、侧屈和抗旋转 |
| 腹部深层 | 腹横肌 | 压缩腹腔、建立腹压和稳定躯干 |
| 核心协同肌 | 膈肌、盆底肌、多裂肌 | 呼吸、腹压和腰盆稳定 |

训练动作：死虫、平板支撑、侧平板、反向卷腹、鸟狗和抗旋转练习。

#### 5. 胸部肌群

胸部肌肉主要负责把上臂向身体前方和内侧推动，并参与肩胛与胸廓稳定。

| 肌群 | 常见肌肉 | 主要功能 |
|---|---|---|
| 胸大肌 | 锁骨部、胸肋部 | 肩水平内收、内收和内旋；锁骨部参与肩屈曲 |
| 胸小肌 | 胸小肌 | 肩胛前倾、前伸和下压 |
| 胸廓侧面 | 前锯肌 | 肩胛前伸、上回旋并使其贴住胸廓 |
| 肋间肌 | 肋间外肌、肋间内肌 | 协助呼吸和稳定胸廓 |

训练动作：墙面或标准俯卧撑、上斜俯卧撑、肩胛俯卧撑和俯卧撑 plus。

#### 6. 肩部肌群

肩部肌肉负责把手臂向不同方向抬起和旋转，同时保持肱骨头在肩关节中稳定。

| 肌群 | 常见肌肉 | 主要功能 |
|---|---|---|
| 三角肌 | 前束、中束、后束 | 肩屈曲、外展、水平外展和后伸 |
| 肩袖 | 冈上肌、冈下肌、小圆肌、肩胛下肌 | 肩外展或内外旋，并稳定肱骨头 |

训练动作：Pike 俯卧撑、侧平举、弹力带水平外展、墙滑、肩胛俯卧撑和弹力带外旋。

三角肌前束已经大量参与俯卧撑等推类动作；居家训练更容易漏掉三角肌中后束和肩袖。

#### 7. 手臂肌群

手臂肌肉负责屈伸肘关节、旋转前臂、控制手腕与手指以及产生抓握力。

| 肌群 | 常见肌肉 | 主要功能 |
|---|---|---|
| 上臂前侧 | 肱二头肌、肱肌、喙肱肌 | 屈肘、前臂旋后；喙肱肌参与肩屈曲和内收 |
| 上臂后侧 | 肱三头肌 | 伸肘；长头还参与肩后伸 |
| 肘部外侧 | 肱桡肌 | 屈肘，尤其在中立握姿时 |
| 前臂屈肌群 | 桡侧腕屈肌、尺侧腕屈肌、掌长肌和指屈肌等 | 屈腕、屈指和抓握 |
| 前臂伸肌群 | 桡侧腕长短伸肌、尺侧腕伸肌和指伸肌等 | 伸腕、伸指和稳定手腕 |

训练动作：窄距俯卧撑、划船、引体向上、背包弯举、锤式弯举、提握和悬垂。

### 容易混淆的归类

- **内收肌位于大腿，但作用于髋关节**：可以归在腿，也可以归在髋；这里按功能放入髋部。
- **前锯肌位于胸廓侧面，但控制肩胛骨**：解剖位置靠胸，训练功能与肩胛稳定关系更大。
- **竖脊肌属于背部，也是核心的一部分**：背部分类强调位置，核心分类强调稳定功能。
- **三角肌后束位于肩后侧，不是背肌**：它与背部肌肉共同完成水平拉和肩水平外展。
- **“腘绳肌”是三个肌肉的合称**：不是一块名为“后腿肌”的单独肌肉。

| 七类主要肌群 | 主要包括 | 居家优先动作 | 动作重点 |
|---|---|---|---|
| 腿 | 股四头肌、腘绳肌、小腿 | 徒手深蹲、反向弓步、分腿蹲、单腿提踵 | 膝盖朝脚尖方向，脚掌三点稳定；轻松超过 15-20 次后改做单腿变式或抱背包 |
| 髋 | 臀大肌、臀中肌、髋周肌群 | 臀桥、单腿臀桥、背包罗马尼亚硬拉、单腿髋铰链 | 向后推髋而不是弯腰；臀桥顶端收臀，不用腰椎过度后仰 |
| 背 | 背阔肌、斜方肌、菱形肌、竖脊肌 | 背包俯身划船、弹力带划船、俯卧 Y-T-W | 先把肩胛向后下方带动，再屈肘；只有 Y-T-W 时更偏上背稳定，对背阔肌负荷有限 |
| 腹 | 腹直肌、腹斜肌、腹横肌等核心肌群 | 死虫、前平板、侧平板、反向卷腹 | 保持肋骨与骨盆相对稳定；先抗伸展、抗旋转，再追求大量卷腹 |
| 胸 | 胸大肌、胸小肌 | 桌边/墙面上斜俯卧撑、跪姿俯卧撑、标准俯卧撑 | 身体保持一条直线，肘部约朝后外侧；选择能稳定完成 6-15 次的难度 |
| 肩 | 三角肌、肩袖、肩胛稳定肌 | Pike 俯卧撑、装水瓶侧平举、墙滑、肩胛俯卧撑 | 先保证肩胛自然上回旋，不耸肩夹颈；侧平举以控制为主，不甩动 |
| 臂 | 肱二头肌、肱三头肌、前臂 | 窄距俯卧撑、背包弯举、背包提握或悬垂 | 推类已大量练三头，拉类已练二头；时间有限时手臂孤立动作放最后 |

### 最该着重练什么

按训练收益排序，先保证四件事：

1. **腿和髋**：深蹲或分腿蹲，加臀桥或髋铰链。不要把“腿”只理解成大腿前侧。
2. **推与拉平衡**：俯卧撑很方便，但必须搭配背包划船、弹力带划船或可靠单杠引体。居家训练最常见的缺口是只推不拉。
3. **核心稳定**：死虫、平板和侧平板比每天冲几百个卷腹更适合作为基础。
4. **肩臂补充**：胸背推拉动作已经带到肩臂，侧平举、弯举等只用于补量，不应挤占主要动作。

### 零健身房全身计划

每周练 3 次，每次约 25-40 分钟，A、B 交替，例如第一周 A-B-A、第二周 B-A-B。背包装书或水瓶即可加阻力；若愿意只添一件器材，优先选可固定的弹力带，因为它最能补足“拉背”。

| 训练 A | 组数 × 次数 | 覆盖 |
|---|---:|---|
| 深蹲或抱背包深蹲 | 3 × 8-15 | 腿、髋、腹部稳定 |
| 合适难度的俯卧撑 | 3 × 6-15 | 胸、肩、肱三头肌 |
| 背包俯身划船或弹力带划船 | 3 × 8-15 | 背、肱二头肌、前臂 |
| 臀桥或单腿臀桥 | 3 × 10-20 | 髋、腿后侧 |
| 死虫 | 3 × 每侧 6-10 | 腹部与躯干稳定 |

| 训练 B | 组数 × 次数 | 覆盖 |
|---|---:|---|
| 反向弓步或保加利亚分腿蹲 | 3 × 每侧 6-12 | 腿、髋 |
| 背包罗马尼亚硬拉 | 3 × 8-15 | 臀、腿后侧、背部稳定 |
| Pike 俯卧撑或上斜俯卧撑 | 3 × 6-12 | 肩、胸、肱三头肌 |
| 背包/弹力带划船或俯卧 Y-T-W | 3 × 8-15 | 背、肩后侧、手臂 |
| 侧平板 | 3 × 每侧 20-40 秒 | 腹斜肌、臀中肌、肩部稳定 |

开始前用 3-5 分钟做原地快走、髋铰链练习、肩绕环和 1 组轻松版动作。组间休息约 60-120 秒。多数动作结束时保留约 1-3 次还能以好动作完成的余力；不必每组都练到力竭。

### 没有大重量，如何持续进步

当某个动作能在所有组都做到次数上限、动作稳定且仍很轻松，按下面顺序只提高一项：

1. 增大完整动作幅度，放慢下放到 3 秒；
2. 每组增加 1-2 次，直到表中上限；
3. 换更难的变式，例如深蹲换分腿蹲、臀桥换单腿臀桥、上斜俯卧撑换标准俯卧撑；
4. 给背包加书或水，或增加一组。

同一肌群明显酸痛时至少隔一天再重练。正常肌肉疲劳、轻微酸胀可以观察；出现关节锐痛、麻木、放射痛、胸痛、异常气短或眩晕时停止训练。已有心血管疾病、近期手术、怀孕、严重骨关节问题或持续疼痛者，应先让医生或合格康复专业人员给出个体化建议。

## 大肌群和小肌群的区别

大肌群和小肌群不是严格解剖学分类，而是训练编排里的实用说法。判断重点通常有 4 个：肌肉体积、跨过的关节和动作范围、能承受的训练负荷、对整体动作和能量消耗的影响。

| 对比 | 大肌群 | 小肌群 |
|---|---|---|
| 典型例子 | 胸大肌、背阔肌、臀大肌、股四头肌、腘绳肌、竖脊肌 | 肱二头肌、肱三头肌、三角肌中后束、肩袖、前臂、小腿、胫骨前肌 |
| 主要特点 | 体积大，常跨过大关节，参与复合动作，能承受较大负荷 | 体积较小，常负责局部动作、细节线条或关节稳定 |
| 训练动作 | 深蹲、硬拉、卧推、划船、引体向上、臀推 | 弯举、下压、侧平举、外旋、提踵、腕屈伸 |
| 训练消耗 | 心肺和代谢压力更大，恢复成本更高 | 局部疲劳明显，整体消耗相对低 |
| 编排优先级 | 通常放在训练前半段，用复合动作优先训练 | 通常放在后半段，用孤立动作补弱项 |
| 增肌塑形价值 | 决定身体大比例：胸背厚度、臀腿形态、基础力量 | 决定细节和稳定：肩线、手臂、小腿、肩关节健康 |

实际训练中，不要把“小肌群”理解成“不重要”。肩袖、前锯肌、臀中肌、腹横肌和足踝稳定肌体积不一定大，但它们会决定肩、髋、膝、踝能不能稳定工作。更实用的顺序是：**大肌群负责基础形态和力量，小肌群负责细节、稳定和短板修补**。

下面是训练和体态分析中最常用的 25 个肌群入口。它不是医学上的固定标准，而是为了查找、训练和排计划而做的实用分组。

| 区域 | 肌群 | 主要位置 | 核心功能 | 常见训练动作 | 查找提示 |

| 胸 | 胸小肌 | 胸大肌深层 | 肩胛前引、下压 | 肩胛控制、拉伸、呼吸训练 | 过紧常见于圆肩 |

## 塑形原则

1. **线条 = 肌肉形态 + 体脂水平 + 体态比例**。力量训练负责“有形”，饮食控制和有氧负责“看得见”，体态和比例决定“好不好看”。
2. **复合动作为主，孤立动作补细节**。深蹲、硬拉、卧推、划船、引体向上、肩推决定大部分基础形态；侧平举、弯举、夹胸、腿弯举、提踵用来补弱项。
3. **每个主要肌群每周训练约 2 次更容易平衡刺激和恢复**。多数动作可做 3-4 组，每组 8-15 次；小腿、肩中后束和核心可适当提高次数。
4. **强度看最后几次是否有挑战**。最后 2-3 次吃力但动作不变形，比追求固定重量或次数更可靠。
5. **局部训练不能局部减脂**。练腹能增强腹肌，但腹肌显现主要取决于整体体脂率。
6. **疼痛不是有效训练的证明**。肌肉酸胀和延迟性酸痛常见；关节刺痛、麻木、放射痛或动作越做越变形，应降低强度或停止。
