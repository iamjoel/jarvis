# 运动项目输出模板

## 高密度摘要

- **一句话结论**：介绍 HIIT、动物流、跑步、瑜伽、壶铃等运动项目时，优先用“是什么、好处、风险、适用情况、怎么做”的轻量结构，而不是百科式长文。
- **核心机制**：按请求选择定位、收益、风险、适用边界和做法；完整专题补充来源，简短解释合并章节。
- **判断入口**：创建或修改运动项目介绍时使用；个性化训练周期根据实际目标和条件安排。
- **常见误区**：简短介绍不必同时生成三个训练等级；收益和风险用足以支持判断的篇幅说明。
- **相关文档**：[技术索引](../../data/technology.md)、[Prompt 优先级](../../data/p/prompt-priority.md)、[Few Shot](../../data/p/prompt-fw-few-shots.md)。

## 按任务规模使用

完整专题可采用下方结构；简短解释或局部修改只处理相关内容。章节可合并，高密度摘要已说明定义时可省略“一句话介绍”。短文摘要可合并字段，只链接实际存在且有用的相关文档。

裁剪结构时保留与问题有关的判断依据、适用边界和可靠来源。发现影响个体建议的重要信息缺失时再追问。

## 模板

```text
请按以下 Markdown 结构介绍【运动项目】，按需要选择章节，保留的一级内容使用 h2。

## 一句话介绍
用一句话说明它是什么，以及主要训练什么能力。

## 好处
用一句话概括它最主要的收益。

## 风险
用一句话概括它最主要的风险，以及风险通常来自哪里。

## 适用情况
说明它适合什么目标、什么人、什么场景。

## 怎么做
根据用户经验和目标选择合适版本；用户需要比较或完整指南时再提供入门、标准、进阶版本。说明：
- 做什么
- 做多久
- 强度
- 频率
- 注意事项

## 不适用情况
说明哪些人或状态需要避免、谨慎或调整。

## 常见错误
按实际需要列出相关错误和修正方式。

## 引用
列出支撑关键判断的来源，包括研究、指南、教材、专业机构页面或高质量综述。
如果没有可靠来源，不要编造，写“暂无可靠引用”。

## 推荐资源
推荐继续学习或实践的资源，例如书籍、课程、视频、网站、App、专业机构或关键词。
优先推荐高质量、可操作、适合入门的资源。
```

## 使用说明

适合用于介绍具体运动项目，例如 HIIT、动物流、跑步、瑜伽、普拉提、壶铃、CrossFit、游泳、攀岩、拳击、跳绳等。

如果用户没有指定运动项目，把【运动项目】替换为用户问题中的具体项目；如果用户同时提到多个项目，按用户需要分别介绍或比较影响选择的关键差异。

当用户要求个性化训练安排时，不要只套用本模板；先使用已有的目标、经验和条件；只追问会影响训练适配或安全的重要缺失信息。
