# 胆固醇（Cholesterol）

## 高密度摘要

胆固醇是人体必需的脂质，参与构成细胞膜，也是合成胆汁酸和类固醇激素的原料。它在血液中由脂蛋白运输，LDL-C 和 HDL-C 分别表示低密度、高密度脂蛋白携带的胆固醇含量。长期 LDL-C 偏高会促进动脉粥样硬化，因此控制 LDL-C 是降脂治疗的重点；HDL-C 较高也不能抵消这一风险。[1][2]

解读化验单时，要把 LDL-C、甘油三酯（TG）与个人心血管风险放在一起看，才能确定合适的治疗目标。血脂受饮食、遗传、肝脏清除能力和基础疾病等多种因素影响；甘油三酯极高时，还需要及时防范急性胰腺炎。[1][5]

## 胆固醇是什么，从哪里来

人体内的胆固醇主要由自身合成，另一部分来自肠道对食物中胆固醇的吸收。正常情况下，自身合成就能满足生理需要，无须依靠食物额外补充胆固醇。肝脏在胆固醇的合成和代谢调节中发挥重要作用，肠道及其他组织也能合成胆固醇。[3][12][13]

自身合成与食物吸收各占多少，会随饮食、吸收效率和个体代谢状态变化；其中由肝脏合成的比例也不能用一个固定数字概括。吃进去的胆固醇增加时，身体通常会减少自身合成，以维持平衡。不过，这种调节有一定限度，反应程度也因人而异，因此膳食胆固醇仍可能影响血脂。[3]

胆固醇难以直接溶于血浆，需要借助脂蛋白颗粒运输。这些颗粒由脂质和蛋白质组成，可以理解为血液中运输脂质的载体。“高密度”和“低密度”描述的就是载体的密度，两者携带的胆固醇在化学上是同一种物质。[2][3]

## 低密度脂蛋白胆固醇（LDL-C）

LDL 是 low-density lipoprotein 的缩写，意为低密度脂蛋白；LDL-C 中的 C 代表 cholesterol，即胆固醇。因此，化验单上的 LDL-C 表示这类颗粒携带的胆固醇含量。

LDL 主要负责运送胆固醇，其中的蛋白质既参与构成颗粒，也帮助细胞识别和摄取它。肝脏分泌的极低密度脂蛋白（VLDL）经过一系列代谢过程，可逐步形成 LDL。随后，肝脏等组织通过细胞表面的 LDL 受体将其从血液中摄取、清除。[3][4]

当部分 LDL 进入血管壁并滞留时，就可能参与斑块形成。这一过程大致分为四步：

1. 部分 LDL 颗粒进入动脉内膜并滞留。
2. 局部脂质积聚与炎症反应相互促进，巨噬细胞摄取脂质后成为泡沫细胞。
3. 随着脂质、细胞和结缔组织积累，逐渐形成动脉粥样硬化斑块。
4. 部分斑块发生破裂或表面侵蚀，触发血小板聚集和凝血，形成血栓，可能突然阻塞血管。[4]

斑块在血管壁内逐渐形成，血栓则可在斑块破损后由凝血过程产生。并非每个斑块都会引发血栓，但 LDL 长期处于较高水平，会增加累积的心血管风险。[4][6]

## 高密度脂蛋白胆固醇（HDL-C）

HDL 是 high-density lipoprotein 的缩写，意为高密度脂蛋白。它参与把外周组织和细胞中的多余胆固醇运回肝脏处理，这一过程称为“胆固醇逆向转运”。HDL-C 因此常被称为“好胆固醇”。[2]

不过，HDL-C 的数值不能完整反映 HDL 的功能。HDL-C 偏低可提示较高的心血管风险，但单纯用药提高这一数值，尚未被可靠证明能降低心血管事件风险。因此，治疗通常着重于控制整体风险，不单独追求提高 HDL-C，也不建议为此开始饮酒。[8]

## 甘油三酯（TG）与胆固醇的区别

甘油三酯（triglycerides）主要用于储存和提供能量，也是血脂四项之一。它与胆固醇是不同的脂质，但可被同一类脂蛋白颗粒携带。[2]

TG 升高常与饮酒、热量摄入过多、肥胖、血糖控制不佳及遗传因素有关。富含 TG 的脂蛋白在代谢过程中会留下残粒，其中携带的胆固醇也可促进动脉粥样硬化。当 TG 特别高时，还会增加急性胰腺炎风险。[5]

## 对健康的影响

LDL-C 长期升高会增加冠心病、心肌梗死、缺血性脑卒中及外周动脉疾病风险。高血压、吸烟、糖尿病等会进一步增加整体风险。多数血脂异常没有明显症状，需要通过检测发现。[2][9]

判断风险时，还要考虑血脂异常的程度和持续时间，以及是否已经发生心脑血管疾病。对高风险患者，规范治疗可能需要把 LDL-C 降到较低水平；是否调整用药应根据个人目标判断，不应仅因化验单标低就自行停药。[6]

## 参考范围与治疗目标

以下数值的单位均为 mmol/L。第一张表采用中国指南的参考标准，适用于尚未发生动脉粥样硬化性心血管疾病、整体风险较低且没有糖尿病的成年人。其他人群需要结合自身情况解读。[1]

| 指标 | 合适或理想水平 | 需要关注 |
|---|---|---|
| 总胆固醇（TC） | ＜5.2 | 5.2～＜6.2 为边缘升高，≥6.2 为升高 |
| LDL-C | ＜3.4 为合适，＜2.6 为理想 | 3.4～＜4.1 为边缘升高，≥4.1 为升高 |
| HDL-C | 不设“越高越好”的治疗目标 | ＜1.0 为降低 |
| 空腹 TG | ＜1.7 | 1.7～＜2.3 为边缘升高，≥2.3 为升高 |

在确定治疗方案时，还需要评估动脉粥样硬化性心血管疾病（ASCVD）风险。按中国指南，风险越高，LDL-C 的控制目标通常越低：[1]

| 风险等级 | LDL-C 目标 |
|---|---|
| 低危 | ＜3.4 |
| 中危、高危 | ＜2.6 |
| 极高危 | ＜1.8，且较治疗前下降超过 50% |
| 超高危 | ＜1.4，且较治疗前下降超过 50% |

风险分层需结合年龄、既往心脑血管病、血压、糖尿病、肾病、吸烟及家族史。例如已有心梗病史的人，即使化验单未标红，也可能未达到治疗目标。不同国家指南的风险等级名称不宜直接互换。[1]

对于 TG，约 ≥5.6 mmol/L（500 mg/dL）时应及时就医评估胰腺炎风险；≥11.3 mmol/L（1,000 mg/dL）时风险进一步增加，应尽快处理。这些数值用于提示何时加强干预，实际风险会随 TG 水平和个人情况连续变化。[5]

## 关联指标与检测

抽血检查“血脂四项”，可以了解 TC、LDL-C、HDL-C 和 TG 的水平。常规筛查可以使用非空腹结果；如果 TG 偏高、怀疑遗传性血脂异常，或需要进一步确定治疗方案，医生可能会安排空腹复查。检查前，应向医生说明近期饮酒、患病和用药情况。[5]

根据检查结果和病史，还可以结合以下指标进一步判断：

| 关联指标 | 补充判断什么 |
|---|---|
| 非 HDL-C＝TC－HDL-C | 反映多类致动脉粥样硬化脂蛋白所携带的胆固醇 |
| 载脂蛋白 B（ApoB） | 用于估计致动脉粥样硬化脂蛋白颗粒的数量；TG 高或 LDL-C 不能充分解释风险时尤其有用 |
| 脂蛋白（a），Lp(a) | 主要受遗传影响的额外风险因素；成人可考虑至少检测一次 |
| 血压、血糖/HbA1c、腰围 | 评估共同影响心血管风险的代谢因素 |
| 甲状腺、肝肾功能 | 按病史查找继发原因，并辅助选择和监测药物 |

TG 明显升高时，部分公式计算的 LDL-C 可能不准确，需要结合实验室方法、非 HDL-C 或 ApoB 判断。调整生活方式或药物后，应按计划复查，确认是否达到目标。血脂严重升高时，需要更及时地处理，并由医生确定复查间隔。[6][9]

## 如何让胆固醇保持在目标范围

管理血脂需要先了解升高的原因，再制定适合自己的方案。除了饮食，遗传因素导致的脂蛋白清除障碍、甲状腺功能减退、糖尿病、肾病以及某些药物，都可能影响血脂水平。[9]

**生活方式：**

- 降 LDL-C：减少肥肉、黄油、奶油等饱和脂肪来源，用适量不饱和脂肪替代；增加燕麦、豆类、蔬菜等纤维来源。
- 降 TG：减少酒精、含糖饮料、甜食和过量精制主食；明显升高时停酒。极高 TG 还需在专业指导下严格限制脂肪。
- 每周累计至少 150 分钟中等强度运动，并逐步增加日常活动；超重者可先以减重 5%～10% 为目标。
- 戒烟，保持规律睡眠。避免为了少吃糖而大量增加黄油、肥肉等高饱和脂肪食物，这可能使 LDL-C 升高。[5][7]

**药物治疗：**

如果需要用药降低 LDL-C，通常以他汀类药物为基础。若仍未达到目标，或出现无法耐受的不良反应，医生可调整方案，考虑依折麦布、PCSK9 抑制剂等。是否用药、选择哪种药物及使用多大剂量，都需要结合个人风险确定。[1][10]

TG 轻中度升高时，仍需重视 LDL-C 和整体心血管风险。TG 严重升高时，可考虑非诺贝特、处方级 ω-3 脂肪酸等；普通鱼油保健品不能替代处方治疗。他汀与贝特类联用需评估肌肉不良反应和肝肾功能，不宜自行搭配。[5][10]

服药期间血脂达标，通常说明治疗正在发挥作用。后续是否调整或继续用药，应结合原有风险和复查结果决定。[10]

若出现持续剧烈的上腹痛，疼痛向背部放射，或伴有反复呕吐，尤其是已知 TG 极高时，应立即就医排查胰腺炎。[11]
