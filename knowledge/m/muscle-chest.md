# 胸部肌肉

## 高密度摘要

胸大肌参与推与上臂合拢，前锯肌帮助肩胛骨运动。训练前用轻推和递增热身组准备；胸前紧绷时可温和伸展，避免把压力压到肩前侧。热身与伸展的安排见[人体肌肉](./muscle-of-human.md#热身与伸展怎么安排)。

## 主要肌肉

- 胸大肌：胸部最主要的肌肉，参与肩关节水平内收、内旋和屈曲。
- 胸小肌：位于胸大肌深层，帮助肩胛骨前伸和下压。
- 前锯肌：位于胸廓外侧，使肩胛骨前伸、上回旋并贴紧胸廓。

前锯肌按**位置**可放在胸廓肌肉中；按**功能**更适合归为肩胛带稳定肌。它从肋骨连到肩胛骨，主要移动和稳定肩胛骨。健身中说的“核心”通常侧重躯干和骨盆稳定肌，前锯肌会在平板支撑等动作中协助稳定上肢，但不是腹肌。

## 常见动作与发力

胸肌常参与向前推和把上臂向身体前方合拢；伸直肘部则还需要肱三头肌配合。

| 常见动作 | 肌肉怎么发力 |
| --- | --- |
| 推开较重的门 | 胸大肌带动上臂向前、向内运动，三角肌前束协同；肱三头肌伸肘，前锯肌帮助肩胛骨向前移动。 |
| 俯卧撑撑起阶段 | 胸大肌收缩，配合肩、手臂肌肉将身体推离地面；前锯肌帮助肩胛骨稳定贴合胸廓。 |
| 俯卧撑下降阶段 | 胸大肌等在拉长时仍保持张力，控制身体下降。下降并不是“胸肌不发力”的阶段。 |
| 张开双臂后拥抱别人 | 胸大肌带动两侧上臂向身体前方合拢；如果继续抱紧物品，肌肉可持续保持张力。 |
| 走路、跑步摆臂 | 胸大肌可协同参与上臂前摆，但胸部不是步行和跑步的主要推进部位，也不需要刻意收紧胸肌。 |

## 怎么练

### 胸大肌：向前推、把上臂合拢

- **俯卧撑：**双手撑地略宽于肩，身体从头到脚保持稳定；屈肘缓慢下降，再推回起点。若标准俯卧撑太难，把双手放在稳固的高台上。避免塌腰、撅臀或为了碰地而失去控制。
- **哑铃卧推：**仰卧在稳固训练凳上，双脚踩地，哑铃从胸部两侧向上推起，再缓慢下降至肩部舒适的位置。让前臂大致竖直，避免重量过大时弹起或把肩膀推向耳朵。
- **补充动作：哑铃飞鸟。**仰卧持轻哑铃，手肘保持微屈，双臂向两侧打开到肩部可控制的位置，再将上臂向胸前合拢。不要把手臂放得过低来强拉肩前侧。

### 前锯肌与胸小肌：控制肩胛骨

**俯卧撑顶端继续推地：**先用高台或跪姿俯卧撑降低难度；肘部伸直后，继续轻轻把地面推远，让肩胛骨沿胸廓向前移动，再回到普通撑姿。避免耸肩和腰部下沉。这个动作侧重前锯肌等肩胛控制肌，不是孤立训练胸小肌；胸小肌通常会在推类动作中参与。

初学可先选俯卧撑或卧推，每周约 2 次，每次 1～2 组、每组 8～15 次；动作稳定后再增加训练量。飞鸟和肩胛控制动作按需要补充。若肩前侧出现明显疼痛，缩小动作幅度或停止该动作。

## 热身与伸展

先参考[通用安排](./muscle-of-human.md#热身与伸展怎么安排)，再按当天动作选择以下练习。下列次数是起步示例，可按熟悉程度与身体反应调整。

### 热身

- 缓慢做双臂开合 8～12 次，接着做高台俯卧撑 6～10 次；让肩胛骨随动作自然移动，保持轻松。
- 卧推先用轻重量做 1～3 组，再逐步加重；正式动作是俯卧撑时，先用更高的支撑面练一组。热身不做到力竭。

### 伸展

**门框胸前伸展：**一侧前臂扶门框，肘部略低于肩，向前迈小步并轻轻转身离开支撑侧，直到胸前有温和牵拉感。每侧保持 20～30 秒，做 1～2 次；不把肩膀向前顶，也不追求手臂越向后越好。肩前侧出现夹痛时停止。
