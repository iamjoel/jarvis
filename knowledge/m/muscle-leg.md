# 腿部肌肉

## 高密度摘要

腿部训练可以按动作理解：**伸膝练大腿前侧，屈膝和伸髋练大腿后侧，夹腿练内侧，抬脚背练小腿前侧，提踵练小腿后侧**。先用深蹲等多关节动作建立整体力量，再用腿弯举、内收和踝部动作补充。动作有训练侧重，但很少只用一块肌肉；不能靠训练某个部位来定点减脂。臀部的训练分工见[臀部肌肉](./muscle-glutes.md)。

## 主要肌肉

- 股四头肌：位于大腿前侧，包括股直肌、股外侧肌、股内侧肌和股中间肌，主要负责伸膝，即把膝盖伸直；股直肌还协助屈髋，即抬起大腿。
- 腘绳肌：位于大腿后侧，包括股二头肌、半腱肌和半膜肌，主要负责屈膝和伸髋，即弯曲膝盖、把大腿向后带。股二头肌短头不跨髋关节，只参与膝部动作。
- 内收肌群：位于大腿内侧，包括大收肌、长收肌、短收肌、股薄肌和耻骨肌等，主要负责把大腿向身体中线收拢；大收肌的一部分也参与伸髋。
- 缝匠肌：从髋部外前侧斜跨大腿，连到膝内侧，是人体最长的肌肉。协助抬腿、大腿外展和外旋，以及屈膝，类似把脚抬向另一侧膝盖时的组合动作。
- 胫骨前肌：位于小腿前侧，主要负责踝关节背屈和足内翻。
- 腓肠肌：位于小腿后侧浅层，主要负责踝关节跖屈，并协助屈膝。
- 比目鱼肌：位于腓肠肌深层，主要负责踝关节跖屈和站立稳定。

## 常见动作与发力

同一块肌肉在不同阶段既可能推动动作，也可能控制减速或稳定关节。“发力”不只发生在向上抬起或向前推进时。

| 常见动作             | 肌肉怎么发力                                                                                       |
| -------------------- | -------------------------------------------------------------------------------------------------- |
| 走路：摆腿、落脚     | 胫骨前肌抬起脚背，帮助脚尖离地；常见的脚跟着地后，它继续发力控制前脚掌放下。膝部肌肉配合控制承重。 |
| 走路：支撑、离地     | 小腿后侧肌群在支撑阶段控制小腿向前移动，并在后续阶段参与踝跖屈和身体推进；肌肉与跟腱共同传递力量。 |
| 跑步：落地承重       | 股四头肌与小腿肌群等承受负荷、控制膝踝运动，配合臀肌稳定支撑。具体分工会随速度和落地方式变化。     |
| 跑步：摆腿接近结束   | 腘绳肌帮助减慢向前摆动的大腿和伸展的小腿，为下一次着地做准备；这是肌肉参与“刹车”的例子。           |
| 上楼、从椅子上站起来 | 股四头肌收缩使膝部伸直，与臀肌的伸髋作用配合，把身体抬高。                                         |
| 下楼、缓慢下蹲       | 股四头肌在膝部弯曲时仍保持张力，控制重心下降；臀部、小腿肌肉共同帮助稳定。                         |
| 踮脚、起跳           | 腓肠肌和比目鱼肌参与踝跖屈，即脚跟抬起、前脚掌向下蹬。起跳还需要股四头肌和臀肌配合。               |

## 不同肌肉怎么练

下面的动作是可选菜单，不需要一次全部做完。“主要练哪里”表示训练侧重；臀部、躯干等通常也会参与稳定或发力。

### 股四头肌：把膝盖伸直

| 动作 | 怎么做 | 关键提示 |
| --- | --- | --- |
| 深蹲／高脚杯深蹲 | 双脚约与肩同宽，徒手或双手在胸前抱哑铃；同时屈髋、屈膝下蹲，再站起。 | 保持全脚掌承重，膝盖大致沿脚尖方向移动；蹲到能稳定控制的深度。膝盖可以超过脚尖，不必为了限制它而过度前倾。 |
| 分腿蹲 | 双脚前后错开，左右留出宽度；身体下沉，前后膝盖弯曲，再以前腿为主站起。 | 可扶稳固支撑物；前脚保持踩实，避免膝盖突然向内塌。也会训练臀肌。 |
| 坐姿腿屈伸 | 坐在器械上，对齐膝关节与器械转轴，滚垫放在小腿下端、踝关节上方；伸膝抬起，再缓慢放下。 | 适合补充直接伸膝训练；不要甩动重量或在顶端猛烈顶膝。 |

**怎么选：**先选深蹲或分腿蹲，需要增加大腿前侧训练时再加腿屈伸。不必通过大幅扭转脚尖来追求“只练股内侧肌”，股四头肌各部分通常共同工作。

### 腘绳肌：既要伸髋，也要屈膝

| 动作 | 怎么做 | 关键提示 |
| --- | --- | --- |
| 罗马尼亚硬拉 | 手持哑铃或杠铃，膝盖微弯；臀部向后推，重量贴近腿下降，感到大腿后侧拉长后再站直。 | 主要动作发生在髋部；保持躯干稳定，不靠弯腰够地面，也不在顶端后仰。下降幅度以能控制背部姿势为准。 |
| 坐姿／俯卧腿弯举 | 调整器械，使膝关节对齐转轴；弯曲膝盖，让脚跟靠近臀部，再控制还原。 | 固定骨盆和大腿，避免抬臀、挺腰借力；这是直接训练屈膝的动作。 |
| 仰卧滑垫腿弯举（居家替代） | 仰卧屈膝，脚跟放在可滑动的毛巾或滑垫上；抬臀后慢慢把脚跟滑远，再拉回。 | 先用双腿、小幅度练习；保持骨盆稳定，拉不回来时缩短滑动距离。 |

**怎么选：**搭配一个伸髋动作和一个屈膝动作，例如罗马尼亚硬拉＋腿弯举，覆盖更完整。深蹲不能充分替代直接的腘绳肌训练；动作当下的肌电活跃程度也不等于长期增肌效果。[ACE 腘绳肌训练研究](https://www.acefitness.org/continuing-education/certified/february-2018/6896/ace-sponsored-research-what-is-the-best-exercise-for-the-hamstrings/)

### 内收肌群：把腿向中间收

| 动作 | 怎么做 | 关键提示 |
| --- | --- | --- |
| 坐姿髋内收（夹腿机） | 坐稳，让靠垫贴住大腿内侧；将双腿向中间夹拢，再缓慢打开。 | 起始张开幅度以舒适为准，不用重量强行拉开双腿，也不要让配重片撞击。 |
| 侧卧下侧腿抬高 | 侧卧，下侧腿伸直，上侧腿跨到身体前方、脚踩地；下侧腿向上抬少许，再缓慢放下。 | 骨盆保持稳定，避免向后滚；抬起的是靠近地面的腿，主要感受大腿内侧用力。 |

**怎么选：**居家先做侧卧内收，健身房可用夹腿机逐步加重。宽站距深蹲也会让内收肌参与，但动作范围与髋膝姿势会影响分工，并非站得越宽越好。[AAOS 髋部训练指南](https://www.orthoinfo.org/recovery/hip-conditioning-program/)

### 缝匠肌：参与组合动作，通常不必单练

可以用**扶墙屈膝抬腿并轻微外展、外旋**来理解它的功能：单手扶墙，一侧膝盖弯曲并抬起，大腿略向外打开，让脚向另一条腿的膝盖方向靠近，再缓慢放回。骨盆朝前，幅度保持舒适，不用手扳脚或扭膝。

这个动作会同时用到其他髋屈肌、外旋肌和屈膝肌，不能视为孤立缝匠肌的增肌动作。一般腿部训练可优先安排上述主要肌群；这里的组合动作主要帮助理解和练习控制。[缝匠肌解剖与功能](https://www.ncbi.nlm.nih.gov/books/NBK532889/)

### 胫骨前肌：脚跟不动，抬起脚背

**靠墙抬脚尖：**背靠墙，双脚向前放一小步，脚跟踩地；将前脚掌和脚趾一起抬向小腿，再缓慢落下。身体不要前后摇晃，感受小腿前侧收紧。

容易时可逐渐把脚放远一点；也可坐姿使用固定稳妥的弹力带，从前方给前脚掌施加阻力，练习抬脚背。注意是在踝关节处抬起整个前脚掌，仅翘脚趾不能充分完成这个动作。

### 腓肠肌：直膝提踵

**站姿提踵：**扶住稳固支撑物，膝盖保持基本伸直；前脚掌压地，抬高脚跟，再缓慢降下。先在平地双腿练习，再逐渐增加负重或改为单腿。

不要反复屈膝弹起，也不要让脚踝明显向内外翻。使用踏板增加幅度时，前脚掌要有充分支撑，下降到可控、舒适的位置。直膝时腓肠肌处于较长的位置，同时比目鱼肌也会参与。

### 比目鱼肌：屈膝提踵

**坐姿提踵：**坐在稳固椅子上，膝盖约弯曲 90°，前脚掌踩地；抬起脚跟，再缓慢放下。需要阻力时，把稳妥的负重放在大腿靠近膝盖的位置，避开髌骨，并用手固定；健身房也可用坐姿提踵机。

屈膝会使跨过膝关节的腓肠肌缩短，减少它的贡献，因此训练更偏向比目鱼肌。但这不代表坐姿只练比目鱼肌，也不能直接推断坐姿让比目鱼肌长得更多：一项 12 周研究发现，两种姿势的比目鱼肌增肌幅度相近，站姿的腓肠肌增长更明显。[站姿与坐姿提踵对比研究](https://www.frontiersin.org/journals/physiology/articles/10.3389/fphys.2023.1272106/full)

## 刚开始怎么安排

以下是一般力量训练的起步参考，可以按恢复情况调整：

- **动作选择：**先选深蹲或分腿蹲、一个伸髋动作、一个腿弯举动作；再按需要添加内收、抬脚背和提踵。直膝、屈膝提踵可以分到两次训练中。
- **训练量：**每个动作先做 1–2 组，熟悉后增加到 2–3 组。深蹲、硬拉等每组 8–12 次，小腿和单关节动作每组 10–20 次；这些是便于起步的范围，并非唯一有效次数。
- **强度与休息：**每组结束时，感觉还能以相同姿势完成约 2–3 次。组间休息约 1–3 分钟，以呼吸恢复、下一组仍能稳定完成为准。
- **频率与进步：**每周练腿 2 次，两次之间至少留一天恢复。能稳定完成次数上限后，再小幅增加重量或动作难度。
- **动作质量：**先用轻重量热身，全程控制，下降阶段不要突然松力。出现关节刺痛或动作引发的持续疼痛时停止该动作并评估原因。
