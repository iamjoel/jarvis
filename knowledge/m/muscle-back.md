# 背部肌肉

## 主要肌肉

- 斜方肌：覆盖上背部，参与肩胛骨上提、后缩、下压和上回旋。
- 背阔肌：覆盖中下背部，主要负责肩关节伸展、内收和内旋。
- 菱形肌：位于肩胛骨之间，主要负责肩胛骨后缩和稳定。
- 竖脊肌：沿脊柱两侧分布，主要负责脊柱伸展、侧屈和姿势维持。
- 多裂肌：位于脊柱深层，帮助稳定各节段椎骨。
- 大圆肌：连接肩胛骨和肱骨，协助肩关节伸展、内收和内旋。

## 常见动作与发力

背部肌肉的分工不同：背阔肌常参与拉动上臂，斜方肌和菱形肌控制肩胛骨，竖脊肌和多裂肌帮助稳定脊柱。

| 常见动作 | 肌肉怎么发力 |
| --- | --- |
| 走路、跑步 | 竖脊肌、多裂肌与腹肌协同维持躯干姿势，控制落地和步伐交替时的晃动；肩背肌肉也参与摆臂和肩胛骨稳定。 |
| 拉门、把物品拉向自己 | 背阔肌和大圆肌参与将上臂向后拉，斜方肌中束和菱形肌帮助肩胛骨后缩；屈肘肌同时配合。 |
| 弯腰后重新直起身体 | 如果脊柱从弯曲回到直立，竖脊肌参与伸展；如果主要在髋部折叠，臀肌和大腿后侧肌肉负责伸髋，背肌更多承担稳定作用。 |
| 背包站立或行走 | 背部肌肉与腹肌共同维持躯干和肩带姿势，抵抗负重引起的姿势变化；具体负担取决于背包位置和重量。 |
| 把手举过头顶 | 斜方肌上、下束与前锯肌共同帮助肩胛骨上回旋，为手臂上举提供配合。 |

## 怎么练

背部可按“把上臂拉向身体、控制肩胛骨、稳定脊柱”三个任务选动作。初学先选一个下拉或划船动作，再加一个躯干稳定动作；每周约 2 次，每个动作从 1～2 组、每组 8～15 次开始。

### 背阔肌、大圆肌：向下或向后拉上臂

- **高位下拉：**坐稳并固定大腿，握住横杆，从头顶上方把手臂向下拉到上胸附近，再控制回升。想象用手肘向身体两侧下拉，避免猛然后仰或把杆拉到颈后。
- **单臂哑铃划船：**一手扶稳固训练凳，躯干保持稳定；另一手持哑铃，让手肘向髋部方向拉，再缓慢放下。避免转动躯干甩起重量。家中也可用固定牢靠的弹力带做划船。

### 斜方肌、菱形肌：控制肩胛骨

**坐姿划船：**双脚踩稳，双手握把手，把手肘向后拉，让肩胛骨自然向后移动；回程允许肩胛骨在控制下向前移动。避免耸肩、含胸猛拉或大幅前后摇晃。斜方肌不同部位的作用不同，这个动作主要照顾中背部的后缩能力；上举时还需要斜方肌与前锯肌协同上回旋。

### 竖脊肌、多裂肌：稳定躯干

**鸟狗式：**四点跪姿，双手在肩下、双膝在髋下；缓慢伸出一侧手臂和对侧腿，再收回换边。保持骨盆和腰背稳定，抬高四肢的幅度以不塌腰、不转髋为准。想练髋铰链也可做轻重量罗马尼亚硬拉：臀部向后推、躯干稳定地前倾再站起；它主要训练臀和大腿后侧，背部更多负责稳定。
