# 背部肌肉

## 主要肌肉

- 斜方肌：覆盖上背部，参与肩胛骨上提、后缩、下压和上回旋。
- 背阔肌：覆盖中下背部，主要负责肩关节伸展、内收和内旋。
- 菱形肌：位于肩胛骨之间，主要负责肩胛骨后缩和稳定。
- 竖脊肌：沿脊柱两侧分布，主要负责脊柱伸展、侧屈和姿势维持。
- 多裂肌：位于脊柱深层，帮助稳定各节段椎骨。
- 大圆肌：连接肩胛骨和肱骨，协助肩关节伸展、内收和内旋。

## 常见动作与发力

背部肌肉的分工不同：背阔肌常参与拉动上臂，斜方肌和菱形肌控制肩胛骨，竖脊肌和多裂肌帮助稳定脊柱。

| 常见动作 | 肌肉怎么发力 |
| --- | --- |
| 走路、跑步 | 竖脊肌、多裂肌与腹肌协同维持躯干姿势，控制落地和步伐交替时的晃动；肩背肌肉也参与摆臂和肩胛骨稳定。 |
| 拉门、把物品拉向自己 | 背阔肌和大圆肌参与将上臂向后拉，斜方肌中束和菱形肌帮助肩胛骨后缩；屈肘肌同时配合。 |
| 弯腰后重新直起身体 | 如果脊柱从弯曲回到直立，竖脊肌参与伸展；如果主要在髋部折叠，臀肌和大腿后侧肌肉负责伸髋，背肌更多承担稳定作用。 |
| 背包站立或行走 | 背部肌肉与腹肌共同维持躯干和肩带姿势，抵抗负重引起的姿势变化；具体负担取决于背包位置和重量。 |
| 把手举过头顶 | 斜方肌上、下束与前锯肌共同帮助肩胛骨上回旋，为手臂上举提供配合。 |
