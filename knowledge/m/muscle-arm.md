# 手臂肌肉

## 主要肌肉

- 肱二头肌：位于上臂前侧，主要负责屈肘和前臂旋后。
- 肱肌：位于肱二头肌深层，是屈肘的重要肌肉。
- 喙肱肌：位于上臂内侧，协助肩关节屈曲和内收。
- 肱三头肌：位于上臂后侧，主要负责伸肘。
- 前臂屈肌群：主要负责屈腕、屈指和抓握。
- 前臂伸肌群：主要负责伸腕、伸指并稳定手腕。

## 常见动作与发力

手臂肌肉主要控制肘、腕和手指；上臂向前后摆动则主要由肩部肌肉参与控制。

| 常见动作 | 肌肉怎么发力 |
| --- | --- |
| 走路、跑步摆臂 | 肱二头肌、肱肌和肱三头肌配合维持或调整肘部弯曲角度。摆臂与腿部运动协调，帮助平衡身体的旋转；不需要一直握紧拳头。 |
| 拿起杯子、把食物送到嘴边 | 肱二头肌和肱肌收缩，使肘部弯曲；前臂和手部肌肉抓稳物品。手心转向上方时，肱二头肌也参与前臂旋后。 |
| 把物品缓慢放回桌上 | 屈肘肌在承受重量的同时逐渐拉长，控制肘部伸直，避免物品直接落下。这是“离心发力”。 |
| 推门、撑起身体 | 肱三头肌收缩使肘部伸直，与胸、肩肌肉共同完成推的动作。 |
| 提购物袋 | 手指屈肌维持抓握，腕部肌肉协同稳定手腕；肘部肌肉按负荷和姿势提供稳定。保持不动时也可能在持续发力。 |

## 怎么练

推、拉类动作已经会训练手臂；想增加手臂训练量时，再从屈肘、伸肘和抓握动作中选择。初学时弯举、伸肘等动态动作各做 1～2 组、每组约 8～15 次；提重行走从能保持姿势的短距离开始。每周约 2 次，两次之间留出恢复时间。选能控制下放的阻力，避免靠躯干摆动完成次数。

### 肱二头肌、肱肌：屈肘

- **哑铃弯举：**站稳，双臂自然下垂，手心朝前，保持上臂大致在身体两侧，弯曲肘部把哑铃抬起，再缓慢放下。不要后仰甩起重量或让手腕过度弯折。手心转向上方时，肱二头肌也参与前臂旋后。
- **锤式弯举：**手心相对、拇指朝上地握哑铃，保持手腕中立，屈肘抬起并控制下降。肱肌与其他屈肘肌一起参与，不能靠握法把肱肌完全孤立出来。

### 肱三头肌：伸肘

**弹力带下压：**把弹力带固定在高处，双肘靠近身体两侧，向下伸直肘部，再慢慢弯回。保持肩和躯干稳定，不用身体下压或甩动代替伸肘。没有弹力带时，可用窄一些的高台俯卧撑训练伸肘，但胸肩也会参与。

### 前臂屈肌、伸肌：抓握与稳定手腕

**提重行走：**双手提握重量合适的哑铃，站直并缓慢走一段距离，保持手腕大致中立、肩膀自然下沉；先用短距离练习，再增加时间或负重。若要分别练腕部，可将前臂支撑在桌面，用很轻的哑铃分别做屈腕和伸腕，缓慢控制，避免甩动手腕。

喙肱肌会随抬臂、向前推等肩关节动作参与，一般无需单独安排动作。出现肘、腕或肩部持续疼痛时，降低阻力或停止引发疼痛的动作。
