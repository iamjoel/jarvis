# 腹部肌肉

## 主要肌肉

- 腹直肌：位于腹部前侧，主要负责躯干屈曲和维持腹压。
- 腹外斜肌：位于腹部浅层两侧，参与躯干旋转、侧屈和屈曲。
- 腹内斜肌：位于腹外斜肌深层，参与躯干旋转、侧屈和稳定。
- 腹横肌：腹壁最深层的肌肉，主要负责维持腹压和稳定腰椎、骨盆。

## 常见动作与发力

腹肌不仅能让身体弯曲，还能在身体几乎不动时抵抗外力，帮助躯干保持稳定。

| 常见动作 | 肌肉怎么发力 |
| --- | --- |
| 走路、跑步 | 腹斜肌、腹横肌等与背部肌肉配合，控制躯干和骨盆的旋转、晃动，为四肢运动提供稳定基础。不是把躯干完全锁死。 |
| 从床上卷起上身 | 腹直肌和腹斜肌参与躯干屈曲，使胸廓向骨盆靠近；继续坐起还会用到髋屈肌，不能把整个起身过程都归给腹肌。 |
| 单手提购物袋 | 腹部两侧肌肉与背部肌肉共同抵抗身体向负重一侧倾斜。外观看起来没动，肌肉仍在发力维持姿势。 |
| 转身拿身旁的物品 | 两侧腹内斜肌、腹外斜肌配合产生并控制躯干旋转，髋部和脚步也会参与转向。 |
| 平板支撑 | 腹肌持续保持张力，抵抗腰部过度下沉和躯干伸展，主要体现为稳定作用。 |

## 怎么练

腹肌训练同时练习弯曲躯干和抵抗躯干移动，不必把腹直肌、腹斜肌和腹横肌理解成能完全分开的训练对象。初学可从下面选一个动态动作、一个稳定动作，每周约 2～3 次；每个动作做 1～2 组。动态动作每组约 8～15 次，静态动作从能保持姿势的短时间开始。

### 腹直肌：控制躯干屈曲

**卷腹：**仰卧屈膝，双脚踩地，呼气时让胸廓缓慢靠近骨盆，只将上背部稍微卷离地面，再控制放下。不要双手拉头颈，也不必把整个上身坐起来；后者会让髋屈肌更多参与。

### 腹横肌、腹斜肌：稳定躯干

- **前平板支撑：**前臂撑地、肘在肩下，收紧腹部和臀部，让躯干保持稳定并持续呼吸。腰部下沉、臀部高翘或憋气时结束这一组；可先用膝盖着地降低难度。
- **死虫式：**仰卧，双臂朝上，髋膝弯曲；缓慢放下一侧手臂和对侧腿，再收回换边。只伸到能保持腰背和骨盆稳定的范围，不靠腰部拱起来换取幅度。
- **侧平板支撑：**侧卧用一侧前臂撑地，肘在肩下，把髋抬起并保持躯干成一直线；左右都练。初学可弯曲下侧膝盖支撑，避免肩部塌陷和骨盆向前后翻转。

动作引起腰部或肩部疼痛时，缩短时间、降低难度或停止该动作。腹部训练能提高力量和控制，但不能单独消除腹部脂肪。
