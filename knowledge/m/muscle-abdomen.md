# 腹部肌肉

## 主要肌肉

- 腹直肌：位于腹部前侧，主要负责躯干屈曲和维持腹压。
- 腹外斜肌：位于腹部浅层两侧，参与躯干旋转、侧屈和屈曲。
- 腹内斜肌：位于腹外斜肌深层，参与躯干旋转、侧屈和稳定。
- 腹横肌：腹壁最深层的肌肉，主要负责维持腹压和稳定腰椎、骨盆。

## 常见动作与发力

腹肌不仅能让身体弯曲，还能在身体几乎不动时抵抗外力，帮助躯干保持稳定。

| 常见动作 | 肌肉怎么发力 |
| --- | --- |
| 走路、跑步 | 腹斜肌、腹横肌等与背部肌肉配合，控制躯干和骨盆的旋转、晃动，为四肢运动提供稳定基础。不是把躯干完全锁死。 |
| 从床上卷起上身 | 腹直肌和腹斜肌参与躯干屈曲，使胸廓向骨盆靠近；继续坐起还会用到髋屈肌，不能把整个起身过程都归给腹肌。 |
| 单手提购物袋 | 腹部两侧肌肉与背部肌肉共同抵抗身体向负重一侧倾斜。外观看起来没动，肌肉仍在发力维持姿势。 |
| 转身拿身旁的物品 | 两侧腹内斜肌、腹外斜肌配合产生并控制躯干旋转，髋部和脚步也会参与转向。 |
| 平板支撑 | 腹肌持续保持张力，抵抗腰部过度下沉和躯干伸展，主要体现为稳定作用。 |
