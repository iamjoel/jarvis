# 臀部肌肉

## 主要肌肉

- 臀大肌：臀部体积最大的肌肉，主要负责髋关节伸展和外旋。
- 臀中肌：位于臀部外上侧，主要负责髋关节外展并稳定骨盆。
- 臀小肌：位于臀中肌深层，协助髋关节外展和内旋。
- 阔筋膜张肌：位于髋部外侧前方，协助髋关节屈曲、外展和骨盆稳定。

## 常见动作与发力

臀大肌更突出地参与伸髋，臀中肌、臀小肌则在单腿支撑时帮助稳定骨盆。

| 常见动作 | 肌肉怎么发力 |
| --- | --- |
| 平地走路 | 站立侧的臀中肌、臀小肌帮助骨盆保持稳定，避免另一侧明显下坠；臀大肌参与着地前后髋部和躯干的控制。 |
| 跑步、加速 | 臀大肌参与髋伸展及支撑期的身体控制，臀中肌等帮助维持单腿支撑时的骨盆稳定。加速、上坡通常对髋伸肌提出更高要求。 |
| 上楼、爬坡 | 前脚承重后，臀大肌与腿部肌肉配合伸髋、伸膝，把身体向上抬升。 |
| 从椅子上站起来 | 躯干前倾后，臀大肌参与伸髋，股四头肌参与伸膝，两者共同将身体抬起并站直。 |
| 缓慢坐下 | 臀大肌与股四头肌等在拉长时维持张力，控制髋膝弯曲和身体下降，避免直接“掉”到椅子上。 |
| 单腿站立、侧向迈步 | 臀中肌、臀小肌帮助控制骨盆和大腿位置；侧向迈步时，髋外展肌还参与将腿向侧面移动。 |

## 怎么练

臀部训练可选一个伸髋动作和一个髋外展或单腿稳定动作。初学时动态动作各做 1～2 组、每组约 8～15 次；单腿动作每侧分别计算，单腿站立按能保持骨盆稳定的时间练习。每周安排约 2 次，两次之间留出恢复时间，能稳定完成动作后再增加阻力。

### 臀大肌：伸髋

- **臀桥：**仰卧屈膝，双脚踩地，收紧腹部并用脚掌推地，把髋部抬到躯干与大腿大致连成直线，再缓慢放下。顶端不靠腰部后仰来追求更高幅度。容易后可在髋部增加稳妥的负重，或改做单腿臀桥。
- **分腿蹲或深蹲：**下蹲时同时弯曲髋和膝，再踩稳地面站起。臀大肌与股四头肌共同发力；选择能保持骨盆、膝盖稳定的深度，不必为了“练臀”刻意把腰挺到过伸。

### 臀中肌、臀小肌：外展与骨盆稳定

- **侧卧髋外展：**侧卧，下侧腿可弯曲支撑，上侧腿伸直并略放在身体后方；保持骨盆不向后翻，将上侧腿抬起一小段，再缓慢落下。先追求骨盆稳定，避免把脚尖大幅转向天花板或甩腿。
- **侧向弹力带行走：**把弹力带套在膝上或踝部，微屈髋膝，向侧面迈小步，再让另一脚跟上；全程保持弹力带张力，膝盖大致朝向脚尖，避免上身左右晃动。
- **单腿站立：**扶住稳固支撑物，用一侧腿站稳，尽量使骨盆保持水平；从短时间开始，再逐渐减少扶持。它更偏向稳定控制，也会用到足踝和躯干肌肉。

阔筋膜张肌会参与髋外展和骨盆稳定，通常随上述动作一起工作，无须为它单独安排一个增肌动作。臀中肌与臀小肌也不能被这些动作完全孤立。出现髋、膝或腰部持续疼痛时，减少幅度或停止引发疼痛的动作。
