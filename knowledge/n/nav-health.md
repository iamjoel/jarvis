# 健康 Roadmap

先明确健康的目标，再判断当前状态，选择优先行动；行动后回到度量，检查效果并调整。

## 1. 怎么算健康？

健康包含身体健康和心理健康。

### 身体健康

| 身体指标            | 健康／理想参考范围（AHA）                                                           |
| ------------------- | ----------------------------------------------------------------------------------- |
| 体重：BMI           | **18.5 ≤ BMI < 25 kg/m²**；BMI＝体重（千克）÷身高（米）²。                          |
| 血脂：非 HDL 胆固醇 | **< 3.4 mmol/L**（< 130 mg/dL，单位换算取近似值）；非 HDL＝总胆固醇－HDL 胆固醇。   |
| 血糖                | 无糖尿病史，**空腹血糖 < 5.6 mmol/L**（< 100 mg/dL，近似值），或 **HbA1c < 5.7%**。 |
| 血压                | **收缩压 < 120 且舒张压 < 80 mmHg**。                                               |

具体见: [生命八要素](../l/lifes-essential-8.md)

#### 体能评估

| 指标 | 参考范围／界限 |
|---|---|
| 心肺耐力：VO₂ max | 按年龄、性别和测试方式查常模，无统一健康区间。 |
| 肌肉力量：握力 | 社区老年人：男性 **<28 kg**、女性 **<18 kg** 提示低握力。 |
| 下肢功能：5 次坐站 | 社区老年人：**<12 秒**为未触发功能下降筛查界限。 |
| 下肢耐力：30 秒坐站 | 例：60–64 岁男性 **≥14 次**、女性 **≥12 次**为未低于 CDC 平均参考；其他年龄见详文。 |
| 行动能力：通常步速 | 社区老年人：6 米步行测试 **≥1.0 m/s**为未触发该项功能下降界限。 |
| 综合行动能力：起立行走计时（TUG） | 老年人：**<12 秒**为未触发该项跌倒风险界限。 |
| 平衡：前后脚串联站立 | 老年人：睁眼、不扶物维持 **≥10 秒**；不足提示跌倒风险增加。 |
| 上肢肌耐力：俯卧撑次数 | 按年龄、性别和动作版本比较，无统一健康合格线；优先追踪同一标准下的变化。 |
| 活动度：踝背屈、肩上举等 | 按具体动作所需范围评估，无统一全身合格线。 |

以上筛查界限不等于体能优秀，也不能直接套用于年轻人。测试方法、年龄分表和来源见[体能评估](../p/physical-fitness-assessment.md)。

## 2. 度量：我现在怎样，最需要关注什么？

结合身体指标、日常功能和心理状态判断现状。参考现代人及自身人群（如白领、老年人）的主要健康问题，找出个人最值得关注的差距与风险。

**这一阶段的产出：少量关键指标，以及最优先的问题。**

## 3. 保持／改进：下一步做什么，做到什么程度？

围绕优先问题安排饮食、运动、睡眠和心理支持；需要时进入诊疗与康复。根据个人起点和生活条件，确定可持续的行动、目标与复评时间。

**这一阶段的产出：一份能执行、能检查效果的行动计划。**

行动后回到第 2 步：有效就保持，效果不足就调整；生活阶段变化时重新审视目标。
