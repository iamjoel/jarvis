# Handoff Example

For a migration that continues across sessions, use a task directory such as `.plans/migration/`.

The plan records the outcome, affected components, completed phases and current constraints. Findings hold compatibility evidence when it is too extensive for the plan. Progress records actual verification results and recovery notes.

Before handing off, record the next action and paths to the relevant artifacts. The next session reads those notes and checks current repository state before acting.

See [more examples](../examples.md) and the maintained [workflow](../SKILL.md).
