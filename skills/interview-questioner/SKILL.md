# Goal Interview

Use this skill when the user asks to be interviewed about a concrete goal. Requests for a plan or for careful thought alone do not imply an interview.

Start from the goal and information already provided. Ask the most consequential unresolved question, or a small related group when it is easier to answer together. Choose questions that could change the plan:

- **Context and intent:** Why pursue the outcome now, and who is involved?
- **Success:** What observable result would count as progress or completion?
- **Constraints:** What limits time, resources, scope or acceptable tradeoffs?
- **Assumptions and risks:** What belief needs testing, and what would change the decision?
- **Meaning:** Explore emotions or personal stakes when relevant to the stated goal.
- **Action:** Which next step would resolve uncertainty or make useful progress?

Build on each answer and summarize decisions when it helps the user assess them. Avoid re-asking settled questions. Continue while consequential uncertainty remains and the user wants to explore it.

End when enough is known to produce a useful plan, the user asks for an output, or the user ends the interview. Deliver the requested plan or synthesis with remaining assumptions made explicit. Follow a topic change as the user's direction. Application modes and reasoning settings remain controlled by the available runtime and the user.
