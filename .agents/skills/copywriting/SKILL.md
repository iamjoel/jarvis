# Copywriting

Write clear marketing copy that helps the intended reader understand the offer and take the requested action.

## Context and Scope

Use the request, supplied copy, and relevant project context. Read `.claude/product-marketing-context.md` if it exists and the current task needs product background. Infer tone and audience from existing material when reasonable.

For a sentence, headline, or CTA, produce the requested copy directly. Ask only when missing information would materially change the result and cannot be reasonably inferred. State assumptions only when they affect how the user should evaluate the draft.

For a full page or positioning strategy, use these as context prompts, not a required questionnaire:

- Page purpose and primary visitor action.
- Audience, problem, objections, and words customers use.
- Product, differentiators, outcomes, and available evidence.
- Traffic source and what visitors already know.

Use available answers and reasonable assumptions to produce a useful draft. Match the amount of context gathering to the task.

## Copy Decisions

- Connect product features to concrete customer outcomes.
- Use customer language and the established brand voice.
- Give each page section a clear purpose and a logical place in the argument.
- Write CTA text that accurately describes the next action or what the visitor receives. A familiar label is appropriate when it is the clearest description.
- Preserve necessary qualifications. Never invent statistics, testimonials, customers, pricing, guarantees, or product capabilities. Ask for essential facts or use clearly marked placeholders when a full draft needs evidence that is unavailable.
- Follow the project's writing style. Use examples and analogies only when they clarify the offer.

## Full Page Work

Choose sections that serve the offer and audience. A page may need a value proposition, supporting explanation, evidence, benefits, product steps, answers to objections, and a CTA. These are options; avoid empty sections or invented proof to complete a template.

- Homepage: Help the main audiences find relevant paths.
- Landing page: Align the offer and primary action with the traffic source.
- Pricing page: Make plan differences, costs, and selection criteria clear.
- Feature page: Connect capabilities to use cases and outcomes.
- About page: Connect the organization's story to what the reader needs to understand.

Read [copy frameworks](references/copy-frameworks.md) only when alternative page structures or headline approaches would help. Treat formulas as optional examples subject to current style rules and factual evidence. For a specific problem connecting ideas, consult [natural transitions](references/natural-transitions.md).

## Deliverable

Match the requested scope:

- Sentence, headline, or CTA: Return the finished copy.
- Full page: Organize copy by the sections the page actually needs; add brief explanations only for consequential choices or assumptions.
- Comparison or requested variants: Provide alternatives and explain meaningful differences.
- SEO metadata: Include it when requested or part of the agreed page deliverable.

Review the draft within the task. Use another available skill only when the user's requested work needs its capability; writing copy does not automatically start a CRO audit, email sequence, experiment, or publishing workflow.
