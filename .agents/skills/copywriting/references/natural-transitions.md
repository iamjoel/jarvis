# Natural Transitions

Use this reference when adjacent ideas feel disconnected. Connect them through their actual relationship and follow the project's writing rules.

- Cause: State what produces the result. Example: “The report updates when a transaction arrives, so the team sees the latest totals.”
- Sequence: Name the next action when order matters. Example: “Choose a plan, then invite your team.”
- Evidence: Attribute the specific claim to the supplied source. Example: “The customer interview identifies manual reconciliation as the main delay.”
- Example: Give a concrete instance that clarifies the preceding claim.
- Comparison: Explain a relevant difference when the reader needs it to decide.

Remove sentences that only announce a new section or repeat a conclusion. A shared subject, concrete verb, or clear heading often provides enough connection. Qualify a claim when the evidence requires it; avoid vague qualifiers that hide missing evidence.

For the ending, state the useful final point or requested action directly. Do not add a stock summary phrase or a rhetorical question and answer.
